# NZR-TFA-Base
Fork of TFA Base that is tailor made for nZombies Rezzurrection. 

Fork of TFA Base that adds a few more gamemode dependent features for nZR. This fork is not related to the TFA team whatsoever.

That simple really, there are not really many ways to shuffle around "nZR", "Fork" ,"Base", and "TFA"

Current Features:
ARC9 Viewbob ported over to TFA with several adjustments
New inspect UI, which inherits the colors you select in the nZR UI settings
New Settings that allow you to tweak and hide certain parts of the inspect menu
Better default settings adjusted for nZR

New Weapon Variables for developers,

- SWEP.Origin : tells which game the weapon comes from
- SWEP.Ability : can be used for PaP ability hints for a unupgraded gun or pap ability for a papped gun
- SWEP.Purpose is now relegated to flavor text, shows up in the in the inspect menu without the Purpose: prefix
